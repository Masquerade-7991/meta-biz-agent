# Helo.ai mark

| File | What it is |
| --- | --- |
| `helo-mark.svg` | The mark as a vector, traced from the brand artwork (the same file as `src/assets/helo-mark.svg`). Use this wherever possible. |
| `helo-mark-1024.png` | The vector rendered 1024 px tall, transparent background, for places that need a bitmap. |
| `helo-mark-extracted.png` | The original artwork (171 × 196 px) with its grey background removed, edges kept soft. |

Colours: red `#ec1c24`, outline and eyes `#0c0a0b`. The browser-tab icons (`public/favicon.svg`, `docs-site/public/favicon.svg`) are the same mark centred in a square.

---
title: Build your AI agent
description: The agent studio, section by section, from a draft to live.
---

Open **AI Agents** and pick an agent, or create one. The studio has one section per part of the agent. Changes in a section are saved with **Save**. If you leave with unsaved changes, a bar reminds you.

Use **Try it** in any section to chat with the agent as a customer would.

## The sections

<Accordions>
<Accordion title="Identity">
What the agent does for customers, its personality, and your business details. Start from an example, or draft it from a document you already have.
</Accordion>
<Accordion title="Knowledge">
What the agent knows:

- questions and answers you write;
- documents you upload;
- websites it reads.

Questions customers asked that the agent couldn't answer show up here, so you can add the answer.
</Accordion>
<Accordion title="Abilities">
**Skills** are things the agent can do in a conversation.

**Rich replies** make answers tappable, with buttons, lists and cards. You build each one in three steps:

1. when it's used;
2. what kind it is;
3. the message, with a live phone preview.
</Accordion>
<Accordion title="Connections">
Connect the agent to your own systems: order lookups, bookings, anything with an API. Each connection shows **Working**, **Failing** or **Not tested yet**. You can test it before customers rely on it.
</Accordion>
<Accordion title="Safety & handoff">
- How the agent answers: only from your knowledge, or chatting naturally.
- Topics it stays away from, and words it never says.
- When and how it hands a chat to your team.
- Whether it checks in on customers who go quiet.
</Accordion>
<Accordion title="Test & Eval">
Chat with the agent, review past test conversations, and run evaluations before going live.
</Accordion>
<Accordion title="Publish">
Choose who the agent answers. Start with **Only my test numbers**, then switch to **Everyone**. You can pause the agent at any time. Customers then get no AI replies, but your team still sees their messages.
</Accordion>
<Accordion title="Performance and Logs">
How the agent is doing once it's answering, and a record of what it did.
</Accordion>
</Accordions>

## Agent status

| Status | Meaning |
| --- | --- |
| **Draft** | Being set up and never switched on. |
| **Testing** | Answers your test numbers only. |
| **Live** | Answers everyone who messages the number. |
| **Paused** | Stopped. Nobody gets AI replies until you resume it. |

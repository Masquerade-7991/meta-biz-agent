Give the agent the facts it needs to answer real questions, and close the gaps customers reveal.

![The Knowledge section with the tabs Website, FAQ, Documents and Business details, and the list of questions the agent couldn't answer this week](/screens/studio-knowledge.webp)

Knowledge has four tabs. Each tab shows a count, and the line above them summarises what the agent knows.

| Tab | What it is |
| --- | --- |
| **Website** | Addresses Meta reads and learns from. The quickest way to start. |
| **FAQ** | Questions and answers you write yourself. |
| **Documents** | Files the agent reads, such as a price list or a policy PDF. |
| **Business details** | Structured facts: description, payment methods, policies, contact details and hours. |

With nothing added, the agent can still chat, but it can't answer specific questions about your business. Adding your website, or 5 to 10 common questions, is the fastest start.

<small>Source: [Meta — Business Agent capabilities](https://developers.facebook.com/documentation/meta-business-agent/capabilities)</small>

## Before you start

- An agent open in the studio.
- Your website address, a few common customer questions, or documents to hand.

## Questions your agent couldn't answer

Once customers or testers are talking to the agent, a panel above the tabs lists questions from the last 7 days that the agent could not answer or handed to a person. Each one shows how often it was asked ("Asked 3×", or "in testing" if it came from a test chat) and a reason: **Couldn't answer** or **Handed to a person**.

Press **Add as FAQ** and the question is carried to the FAQ tab so you can write the answer. Answer it once and the agent knows next time. The panel stays hidden when there is nothing to show.

## Website

<Steps>
<Step>
### Add the address
Type your address (for example `https://yourbusiness.com`) under **Add a website** and press **Add**. To add several, press **Add several** and put one address per line.
</Step>
<Step>
### Wait for it to be read
Each website shows its progress: **Queued**, then **Reading**, then **Ready**. Large sites can take a few minutes.
</Step>
<Step>
### Check it
Ask the agent a question that only a page on your site can answer, using **Try it**.
</Step>
</Steps>

Meta reads the whole site from the address you give, and reads it again now and then. If you add an address already covered by another one in your list, the console tells you.

| Status | What it means |
| --- | --- |
| **Queued** | Waiting for Meta to start reading. |
| **Reading** | Meta is reading the site. |
| **Ready** | The agent can answer from this site. |
| **Taking a while** | Meta is still working on it. Check back later, or choose **Read again**. |
| **Nothing usable** | Meta read the site but found no text it could use. Try a page with more written content, like your FAQ or help page. |
| **Couldn't read** | Meta couldn't read the site. Open **Why might this happen?** for common causes. |

Each site also has **Read again**, **Edit address** and **Remove**.

<Callout type="warn">
Don't rely on the page count. Meta sometimes reports 0 pages even when the agent has learned from the site. To check a site worked, ask the agent a question that only that site answers.
</Callout>

If a site fails, the usual causes are a site that blocks automatic readers, pages that need a login, or text that only appears after the page runs in a browser. Adding a simpler page, like your help or FAQ page, often fixes it.

<small>Source: [Meta — Website knowledge](https://developers.facebook.com/documentation/meta-business-agent/reference/configure/agent-knowledge-websites)</small>

## FAQ

Press **Add row** to write a question and its answer, or **Import FAQs from CSV** to bring many in at once (choose which column holds the questions and which the answers).

Tips from Meta and the console:

- Keep each entry to **one specific question**, and write the answer so it makes sense on its own. The agent reads each entry separately.
- Avoid near-duplicates. The console warns you when a question looks like one you already have.
- Keep the list manageable. The console warns when you have a lot of entries, because past a few hundred the agent gets worse at finding the right answer.
- Use the search box to find an entry. Each row can be edited or deleted. The agent stops using a deleted entry immediately.

<small>Source: [Meta — FAQ knowledge](https://developers.facebook.com/documentation/meta-business-agent/reference/configure/agent-knowledge-faqs)</small>

## Documents

Drop files onto the upload area or click it to browse. Accepted types are PDF, DOC, DOCX, PNG, JPG and JPEG, up to 100 MB per file. CSV and XLSX files only work when Meta has switched them on for your account; if not, the console says so and suggests saving the file as a PDF.

Each document can be replaced or deleted. A deleted document can't be brought back, and the agent stops using it.

<small>Source: [Meta — File knowledge](https://developers.facebook.com/documentation/meta-business-agent/reference/configure/agent-knowledge-files)</small>

## Business details

Structured facts the agent can use in any conversation. Fill in what applies and skip the rest.

- **Business description**: what you sell and who you serve.
- **Payment methods**.
- **Your policies**: cancellations and refunds, how customers buy or book, delivery or fulfilment, and more.
- **How customers reach you**: contact email, business address and business hours.

Business hours are your hours, not the agent's. The agent is available at all times. Setting every day to closed tells the agent you are never open, so the console asks you to confirm it.

This tab has its own **Save** button.

## Good to know

- Tell the agent less, but clearly. A short, accurate FAQ beats a long, messy one.
- Don't repeat in FAQs what you already put under Business details.

## If something goes wrong

| Message | What to do |
| --- | --- |
| **This does not look like a website address.** | Check the address, including `https://`. |
| **This question already exists. Edit the existing entry instead of adding a new one.** | Find and edit the existing FAQ. |
| **Document type is not supported.** | Use one of the accepted file types. |
| **File exceeds 100 MB.** | Compress it or split it. |
| **Could not save. Nothing was lost.** | Try again. |
| **Could not delete. The item is still here.** | Try again. |

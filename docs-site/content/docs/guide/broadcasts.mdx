Supervisors, admins and owners send broadcasts.

## Templates

WhatsApp only allows messages that start a conversation if they use a template Meta has approved. Create one in **Broadcasts › Templates**:

- **Name:** lowercase letters, numbers and `_`, which is WhatsApp's rule.
- **Header and footer:** both optional.
- **Body:** use placeholders for things like the customer's first name, and give examples for Meta's review.
- **Buttons:** up to 3.

Meta reviews each template. Only approved templates can be sent.

## Send a broadcast

1. Name it. Only your team sees the name.
2. Pick the audience: a segment, or every contact who hasn't opted out.
3. Pick a template and fill it in.
4. Send now or schedule it.

After it goes out, the broadcast shows how many messages were sent, delivered, read and replied to. **What didn't go out** lists the failures and why.

<Callout type="warn">
People who opted out are always left out. Meta charges for each message, so check the audience size before sending.
</Callout>
